# Allen & Grace Wedding Invitation

Wedding date: September 3, 2027
Ceremony: 3:00 PM
Venue: Myon's Cuisine
RSVP deadline: January 1, 2027
RSVP: CreatEcards
Theme/Dress code: Rustic

The invitation is mobile-first and includes an animated envelope opening, countdown,
Google Maps search button, rustic styling, and the uploaded couple photo.

To add the actual background music, replace the music placeholder in index.html
with a direct audio file URL or add a local audio file and set its source in the script.

For publishing, upload index.html and couple-photo.jpeg together to a static hosting
service such as GitHub Pages or Cloudflare Pages.
